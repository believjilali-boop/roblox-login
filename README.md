
Ceci est un site de phishing Roblox conçu pour collecter des informations auprès des utilisateurs, notamment leurs noms d'utilisateur, mots de passe et adresses IP, qui sont ensuite envoyées à un webhook Discord.

C'est un fork de [RoPass](https://github.com/dtbsisco/RoPass) avec une apparence moderne, en adéquation avec l'actuelle apparence de Roblox.
Voir les instructions sur le dépôt original.
